# Study Stats
The ultimate revision/study statistic analysis tool to help individuals struggling with ADHD. 

## Description
Currently, there are no functions in Study Stats, but some of the planned functions are:
- Finding the overall trend of predicted task length and actual time taken
	-  Can be done on specific subjects
	-  Can be done on specific task-types
- Utilizing NLP or SpaCy to analyze sentiment on specific tasks and how to support user
- Identifying which tasks are skipped or avoided to help prompt user to reflect on potential reasons for avoidance
- Identifying patterns like time of day tasks are completed and user's productiveness at the time
- Finding psychology literary papers to provide evidence-based methods to improve productivity
